# fhelper 文档引用美化 — 设计说明

日期：2026-07-08  
状态：待用户审阅  
范围：并入现有插件 `fhelper`，通用 Tab 增加开关

## 1. 背景与目标

启用后，仅对「引用目标为**文档块**」的块引用做样式增强：

- 下划线
- 显示该文档自身图标（删除自定义图标后回落默认 📄）
- 图标变更后，已打开编辑器内对应引用同步更新
- 目标文档被删除时改为删除线样式；文档恢复后恢复文档引用样式
- 已样式化的引用作为原子单元：不可半截编辑，删除即删整条引用

关闭开关：去掉样式与监听，不改写引用内容本身。

## 2. 关键澄清：两处「d」

| 位置 | 字段 | 含义 |
|------|------|------|
| 引用标记 | `TextMarkBlockRefSubtype` / DOM `data-subtype` | `d` = **动态**锚文本；`s` = **静态** |
| 被引用目标 | `blocks.type`（按 `TextMarkBlockRefID` / `data-id` 查询） | `d` = **文档块**；`p`/`h`/… = 其它块类型 |

**禁止**用引用上的 `subtype === "d"`（或「引用多半是 d」）判断是否为文档。  
**必须**用引用目标 ID 查询结果判断。

思源动态引用会在文档改名时自动同步锚文字；本功能**不**负责标题同步，只负责样式层（下划线 / 图标 / 删除线）。

## 3. 用户可见规则

对每个 `span[data-type~="block-ref"]`：

1. 读取 `data-id`
2. 查询目标块是否存在及其类型 / 文档图标
3. 分类渲染：

| 查询结果 | 样式 | 说明 |
|----------|------|------|
| 存在且 `type = 'd'` | 下划线 + 文档图标 | 无自定义 icon → 默认 📄 |
| 存在且 **不是** 文档 | **不处理** | 保持思源原生 |
| ID 不存在 / 已删除 | **删除线**（无下划线、无文档图标） | 失效引用 |

### 原子交互

- 对象是**整条块引用**（该 `block-ref` 节点），不是整段段落
- 倾向：`contenteditable="false"`（或等价）包裹已处理引用
- 选中 / Backspace / Delete：整条引用一起删除，不可编辑半截锚文本

### 图标回落

- 文档删除自定义图标 → 引用处显示默认 📄（仍保留下划线）

## 4. 架构（方案 A）

采用「编辑器加载批量查询 + DOM 打标」为主，「轻量 MutationObserver」补新节点，「窄范围事件」做增量同步。

```
开关开启
  → 注入 CSS（文档引用 / 失效引用）
  → 编辑器加载：扫描可见 ref → 批量查 ID → 打标 + 图标
  → MutationObserver：仅处理新出现的 ref
  → 事件：icon 变 / 文档删除 / 文档恢复 → 按 ID 增量更新
开关关闭
  → 卸 CSS、摘标记、关监听、清缓存占用
```

### 缓存

`docId → { exists, isDoc, icon }`

- `exists=false`：失效引用 → 删除线
- `exists=true && isDoc=true`：文档引用样式
- `exists=true && isDoc=false`：跳过（不打文档样式）

### 查询

- 批量 SQL / `fetchPost` 查询目标 `type` 与文档 `icon` 属性
- 禁止对每个 ref 在热路径上串行单查（打开大文档时批量收齐 ID）

### 事件与刷新范围（窄）

| 事件 | 行为 |
|------|------|
| `loaded-protyle-static` / `dynamic` 等 | 对本编辑器可见 ref 批量分类渲染 |
| 文档 **图标** 变更 | 更新缓存中该文档 ID；仅重绘已打开编辑器里 `data-id` 匹配的节点 |
| 文档 **删除** | 命中该 ID → 改为删除线样式 |
| 文档 **恢复** | 重查确认是文档 → 恢复下划线 + 图标 |
| 文档 **标题** 变更 | **不主动处理**（交给思源动态引用）；样式层若被 DOM 刷新冲掉，依赖 Observer / 补标恢复 |
| 其它无关属性 | 忽略 |

**不做**：任意属性变更即重扫所有打开文档全文。

### DOM 刷新韧性

思源更新动态锚文本时可能改写引用节点 DOM。需要：

- Observer 或加载后补标，避免 class / 图标 / `contenteditable` 丢失
- 标题变更本身不触发我方库查询

## 5. 设置与配置

- 位置：`fhelper` 设置 → **通用** Tab → 「输入 / 引用」类分区
- 开关文案示例：`文档引用美化`（中英文 i18n）
- 配置字段建议：`docRefStyle.enabled`（布尔，默认 `false`）
- 持久化：与现有 `fhelper-config.json` 同文件，加载时兼容缺省字段

## 6. 非目标

- 不为段落 / 标题等非文档引用加本套样式
- 不用 `subtype=d` 作为文档判断
- 不实现自定义下划线色系主题编辑器（首版固定主题变量即可）
- 不在关闭时删除用户笔记中的引用数据

## 7. 风险与对策

| 风险 | 对策 |
|------|------|
| 大文档大量引用 | 批量查询 + 仅当前编辑器 / 可见区优先 |
| 动态锚文本更新冲掉样式 | Observer / 补标 |
| 自定义图标格式（emoji 码 / 自定义图） | 对齐思源文档树图标渲染约定；无法解析时回落 📄 |
| `contenteditable=false` 与输入法 / 选区 | 测 Backspace、选中、复制；必要时退化为整节点选中删除 |

## 8. 验收标准

1. 引用文档：有下划线 + 该文档图标；删文档图标后为 📄  
2. 引用段落 / 标题：外观与原生一致（本功能不干预）  
3. 引用目标删除后：该引用为删除线，无下划线 / 文档图标  
4. 文档从回收站恢复后：对应引用恢复文档样式  
5. 改文档图标：已打开文档中的引用图标同步  
6. 改文档标题：锚文字由思源更新；本功能样式仍在  
7. 对已样式化引用 Backspace / Delete：整条引用删除，非半截  
8. 关闭开关：样式与监听消失，引用内容完好
