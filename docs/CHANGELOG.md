# 重大设计 / 架构演变

记录方向性变化与模块级结论，不是完整 git log。

## 2026-07-08 ~ 2026-07-09 — 文档引用美化（v1.8.0 → v1.8.2）

- **初版**：按目标块类型装饰文档引用（下划线 + 图标）；失效引用删除线；原子单元；设置开关 `docRefStyle.enabled`。
- **按文档分桶缓存**：`docRefByDoc` / `docRefDirtyDocs`；关 Tab 清分桶；切换命中缓存零 SQL；`createdoc` 防抖重建；新引用短重试。
- **编辑韧性**：回车 / 动态锚文本重建节点时，Observer 对已有 `data-id` 只补标、不清缓存；50ms 防抖补回丢失 class。

详见 [design/2026-07-08-doc-ref-style.md](design/2026-07-08-doc-ref-style.md)。

## 2026-07-09 — 子文档索引（自 v1.9.x）

- 仅一层直接子文档；父文档末尾增量追加标准动态块引用 `((id 'title'))`。
- 已有引用按 `refs.def_block_id` 跳过；直接子文档与侧栏一致，用文件树 API，不用 `blocks.parent_id`。
- 入口：设置页全局 / 笔记本批处理；编辑器工具栏与命令处理当前文档。

详见 [design/2026-07-09-child-doc-index.md](design/2026-07-09-child-doc-index.md)。

## 2026-08-04 — 导航植入查子文档仅 SQL

- DOM 导航植入：**仅 SQL** 查子文档，禁止对可能无文件夹的路径调用 `listDocsByPath`。

详见 [design/2026-08-04-child-nav-body-sql.md](design/2026-08-04-child-nav-body-sql.md)。

## 2026-08-31 — 去掉子文档索引；顶层笔记本文档可列出子文档

- **子文档索引**整模块移除（设置、面包屑、工具栏、命令、文末写入引用）；定位 / 归集 / 删除未引用仍保留。
- **子文档导航植入**按思源顶层笔记本文档的虚拟父子关系列举根层子文档，不再用物理路径 `/<boxID>/` 去查。
- **正文子文档导航**从现行模块表与代码中清掉（含打开文档时删除旧正文导航块的遗留清理）。

详见 [design/2026-08-31-child-nav-box-doc.md](design/2026-08-31-child-nav-box-doc.md)。

## 2026-09-02 — 子文档导航：YAML 后挂载与夹缝备注

- 打开文档自动挂载；有 YAML frontmatter 时插在闭合 `---` 之后，否则在正文起始。
- 仅展示当前层子文档；备注按需插入为可编辑段落，与显示顺序存在 `custom-fhelper-child-nav-layout`，不写正文块；拖动排序不改侧栏。
- 面板细边框；添加与拖动放在行左侧 gutter，悬浮显示、不撑开行高；`childDocWidget.enabled` 默认开启。

详见 [design/2026-09-02-child-nav-layout.md](design/2026-09-02-child-nav-layout.md)（已被正文自动引用块方案替代）。

## 2026-09-02 — 子文档导航改为正文自动引用块

- 去掉 DOM 挂件与夹缝备注。
- 打开文档时若缺导航块则用 `appendBlock` 接到文末；块带 `custom-fhelper-child-nav`，缺子文档则补、子文档没了则删自动块；手动引用不动。已有自动块不重排。
- 不再写导航结束 `---`；打开时清掉旧分隔线。
- 这些引用进入正文，MCP 可读到。
- 带标记的自动引用用样式表做成文档链接外观（正文色、加粗、下划线、文档图标），不写进 span，避免块属性泄漏。
- 该外观由设置「子文档引用美化」（`docRefStyle.enabled`）控制；原「全部文档引用打标」停用。
- 设置「子文档导航植入」分组含植入、引用美化、隐藏文档树新建子文档按钮；去掉独立「文档树」分组。
- 斜杠「新建子文档块」：固定排在斜杠菜单最顶；创建子文档后先清掉 `/`，再把带导航标记的引用写进同一行，然后打开子文档。

详见 [design/2026-09-02-child-nav-body-refs.md](design/2026-09-02-child-nav-body-refs.md)。

## 2026-09-02 — 子文档导航改为 H5 引用，去掉大纲注入

- 自动生成与斜杠写入形态改为 `##### ((id '标题'))`（五级标题包裹文档引用），自定义属性打在该标题块上。
- 删除大纲 DOM 注入（含缓存、Observer、`Outline.update` 补丁与相关 CSS）；大纲靠原生标题收录。
- 同步时将仍为段落的旧自动块升级为 H5，保留块 id 与导航属性。

详见 [design/2026-09-02-child-nav-body-refs.md](design/2026-09-02-child-nav-body-refs.md)。

## 2026-09-02 — 去掉引用归集与删除未引用

- 面包屑更多菜单、工具栏、命令中的「引用文档归为子文档」「删除未引用子文档」及其实现一并移除。
- 文档树辅助只保留「定位到文档树」。
